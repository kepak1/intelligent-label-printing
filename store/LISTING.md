## English (default)

### Name
Intelligent label printing

### Short description
Open-source courier label printing: crops A4/A6 label PDFs and prints them on your label or A4 printer in one click.

### Detailed description

**Print courier labels in one click.**
No subscription, no account, no paid version – every feature is available to everyone, and the code is open source.

Some carriers give you the label as a full A6 page, others put it on a quarter of an A4 sheet. This extension handles both: it finds the label in the PDF, crops the white margins, and prints it the right way on the printer you choose.

★ WHAT IT DOES
• Detects the label on every page of the PDF and crops away the white space.
• Skips instructions and small text next to the label automatically.
• Splits several labels on one A4 page into separate labels.
• Rotates and scales the label to fit your paper.
• Prints directly to the selected printer – no print dialog (with the helper app).

★ WORKS WITH YOUR PRINTER
• Label printers (Brother QL, Zebra, Munbyn, Xprinter and other thermal printers): the label fills the whole label – A6, 100×150 mm, 4×6" or any custom size.
• Ordinary A4 printers: the label is printed in an exact A6 area (105×148 mm) with cut lines – cut it out and stick it on. Optionally 2 or 4 labels per sheet.
• Paper sizes and printable areas are read from the printer driver, including your own custom sizes.

★ PRINTER PROFILES
Set up several printers as profiles (e.g. "Label printer" and "A4 office printer") and switch between them with one click. Export the profiles to a file and import them on another computer.

★ MANY WAYS TO PRINT
• "Print PDF from this tab" in the toolbar popup.
• Right-click a PDF link → Print with a chosen profile.
• Keyboard shortcut Alt+Shift+P.
• One click on any recently downloaded PDF.
• Optional automatic printing of PDFs downloaded from chosen sites (e.g. your courier's website).
• Preview showing the crop, scale and rotation before printing.

★ PRIVATE BY DESIGN
All processing happens on your computer. Your labels – with your customers' names and addresses – are never uploaded anywhere. No tracking, no analytics.

★ ONE-CLICK PRINTING NEEDS A SMALL HELPER APP
Chrome does not let extensions print to a chosen printer without showing a dialog. A small open-source helper app (macOS and Windows) does that part. The extension shows you where to download it and how to install it. Without the helper the extension still crops your labels and prints through the normal print dialog.

★ OPEN SOURCE
Source code: https://github.com/kepak1/intelligent-label-printing (MIT license).
If the extension saves you time, you can support it on Ko-fi: https://ko-fi.com/kepak1 – donations pay for code signing, so the helper installs without security warnings. Donating is entirely optional and does not unlock anything – every feature is available to everyone.

Interface languages: English, Polish.

## Privacy practices tab

### Single purpose
Crops courier/shipping label PDFs to the label itself and prints them on the printer and paper size chosen by the user.

### Permission justifications
| Permission | Justification |
|---|---|
| `nativeMessaging` | Sends the cropped label to the user's optional helper app, which prints it on the chosen printer without a print dialog and lists the installed printers and paper sizes. |
| `activeTab` | Reads the label PDF from the tab where the user clicked the toolbar button, used the keyboard shortcut or the right-click menu. Access is limited to that tab and that moment; the extension has no host permissions and does not inject scripts into pages. |
| `downloads` | Lists recently downloaded PDFs in the popup so they can be printed with one click; downloads a right-clicked PDF link from another site through Chrome (using the user's login) so it can be printed; and, only if the user enables it, prints PDFs downloaded from domains the user specifies. |
| `contextMenus` | Adds "Print with profile …" to the right-click menu of links and pages. |
| `offscreen` | Renders and crops PDFs (pdf.js) in an offscreen document, because service workers have no canvas. |
| `storage` | Saves the user's printer profiles and settings locally. |
| `notifications` | Confirms that a label was sent to the printer, or explains why printing failed. |

### Remote code
No, I am not using remote code. All code (including pdf.js and pdf-lib) is bundled in the package.

### Data usage
Check: **Personally identifiable information** and **Website content** (label PDFs contain names and addresses and are read from websites), with these certifications:
- I do not sell or transfer user data to third parties.
- I do not use or transfer user data for purposes unrelated to the item's single purpose.
- I do not use or transfer user data to determine creditworthiness or for lending purposes.

All processing is local. Nothing is sent to any server operated by the developer.

### Privacy policy URL
https://github.com/kepak1/intelligent-label-printing/blob/main/PRIVACY.md
